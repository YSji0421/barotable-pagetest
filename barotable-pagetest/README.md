> 바로 보기: https://aceoberon.github.io/barotable/ (GitHub Pages 설정 후)

바로테이블 화면 설계를 같이 보기 위한 버전입니다. 백엔드 없이, 데이터는 모두 하드코딩돼 있습니다.

## 여는 방법
`src/main/resources/templates/index.html`을 브라우저로 열면 됩니다.
(입력값이 화면 사이에 안 이어지면 `src/main/resources`에서 `python -m http.server` 실행 후
`http://localhost:8000/templates/index.html`로 접속)

CSS·JS를 고쳐서 배포할 때는 레포 루트에서 `python tools/bump-asset-version.py <새 버전>`을 실행해 파일 주소의 `?v=` 값을 바꿔 주세요.
GitHub Pages가 파일을 약 10분 캐시해서, 안 바꾸면 휴대폰에서 새 HTML과 예전 CSS/JS가 섞여 기능이 동작하지 않을 수 있습니다.

## 동작하는 것
1. **AI 채팅 팝업 (좌석 선택 화면):** 문장에서 날짜·시간·인원·요청사항을 정리하고, 확인하면 좌석도 조건에 적용합니다. 규칙 파서가 먼저 읽고, 빈 칸이 남을 때만 로컬 LLM을 부릅니다. (서버가 없어 LLM 쪽은 고정 응답)
2. **좌석 선택 (C-03):** 날짜·시간과 이용 시간이 겹치는 예약이 있는 자리는 막히고, 남은 자리 중 채팅 요청(창가·바 등)과 맞는 가장 작은 테이블을 추천합니다. 오늘은 기준 시각 이후만 고를 수 있습니다. "좌석도 크게 보기"로 전체 화면에서 확대해 고를 수 있고(뒤로가기로 닫힘, 가로 화면 대응), 휴대폰에서는 화면 아래 고정 바에서 추천·선택 확인과 다음 단계 이동을 바로 할 수 있습니다.
3. **날짜·시간 선택:** 2026년 10월만, 운영 조건의 영업시간 안에서 30분 단위 (기본 11:30–21:30, 브레이크 15:00–17:00 선택 불가)
4. **화면 이동:** 버튼과 상단 PAGE TEST 바의 화면 목록
5. **비회원 조회·취소 (C-07):** 예약 완료 메일의 조회 링크(무작위 토큰, 방문일이 지나면 만료)로 바로 조회합니다. 링크를 잃어버리면 이메일로 다시 받고(예약 유무와 상관없이 같은 안내), 예약번호 + 연락처 조회는 보조로 남겼습니다. 예약 시간 전의 확정 예약만 취소됩니다.
6. **점주 대시보드 (O-02):** 테이블별 시간표, 상태 필터, 예약 선택, 방문 완료, 노쇼 처리·되돌리기, 테이블 옮기기, 워크인 배정. 기준 시각은 10월 5일 19:00으로 고정입니다.
7. **손님 배정 (O-05):** 예약 없이 온 손님 퀵 배정, 전화 예약 손님 배정(브레이크·지난 시간 제외), 배정 삭제
8. **좌석도 편집 (O-03):** 층·구역 관리, 테이블·시설 추가(끌어다 놓기)·이동·크기 조절·45° 회전·확대/축소, 저장 전 검사. 예약이 있거나 손님이 이용 중인 테이블은 지우거나 번호를 바꿀 수 없습니다. 저장하면 손님 좌석도와 대시보드에 반영됩니다.
9. **운영 조건 (O-04):** 영업시간·브레이크, 인원 범위, 이용 시간, 시간대별 한도, 노쇼 경고, 자리 직접 고르기, 알림, AI 해석 방식을 저장하면 손님 화면·채팅·손님 배정·대시보드에 반영됩니다.
10. **서비스 관리자 (A-02):** 로그인 화면에서 "서비스 관리자"를 고르면 점주 계정 승인 화면으로 갑니다.
11. **화면 구성도 (발표용):** 상단 PAGE TEST 바의 "화면 구성도" 버튼이나 M 키로 오른쪽 패널을 엽니다. 지금 화면의 영역별 번호·설명(화면 위에도 번호 표시), 전체 화면 흐름, 화면 사이 데이터 연결을 보여 줍니다. "휴대폰 · QR" 탭에서는 지금 화면을 390×844 휴대폰 틀 안에 같이 띄우고, 미리보기 주소 QR(크게 보기 포함)을 보여 줍니다. 화면을 옮겨도 열린 상태가 유지됩니다.

5~10에서 바꾼 내용은 브라우저 탭의 sessionStorage에 저장돼 같은 탭에서 화면을 옮겨도 이어집니다. 새 탭으로 열면 처음 상태이고, 대시보드의 "시연 데이터 초기화"나 운영 조건의 "기본값으로"로도 되돌릴 수 있습니다.
